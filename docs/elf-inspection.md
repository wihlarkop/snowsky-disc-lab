# Offline ELF inspection

`snowsky_disc_lab.elf_inspection.inspect_elf(path)` reads one locally selected file and returns a frozen `ElfInspection` summary. It does not execute, load, compile, patch, modify, or launch the file, and it does not access firmware or the network. This is a narrow M2-02 inspection primitive; it does not complete M2 or authorize an execution path.

The report records the selected path and file name, byte size, and SHA-256 of the exact bytes read. It identifies ELF32/ELF64, byte order, machine ID/name, file type, linkage metadata, optional `PT_INTERP`, and `DT_NEEDED` names. Linkage is `dynamic` when a linked executable/shared object declares `PT_DYNAMIC` or `PT_INTERP`; it is `static` only for an executable with a `PT_LOAD` segment and no dynamic metadata. Relocatable, shared objects without conclusive linkage data, and other inconclusive objects report `UNKNOWN`.

MIPS reports retain raw `e_flags` and decode only known O32/O64/EABI values and the N32 ABI2 flag. Conflicting ABI2 and ABI-field bits report `UNKNOWN`; a `PT_MIPS_ABIFLAGS` segment on a non-MIPS machine is refused. Floating-point ABI is `UNKNOWN` unless a version-zero `PT_MIPS_ABIFLAGS` segment explicitly declares soft-float (code 3) or one of the known hard-float O32 modes (codes 1 or 2). Missing, unsupported, or other ABI-flag versions remain `UNKNOWN`. `compatibility` is always `UNKNOWN`: this parser does not compare against a reviewed runner, firmware, sysroot, libraries, required filesystem paths, or UI protocol and does not claim MIPS32-LE runtime compatibility.

The default and maximum input limit is 128 MiB; callers may request a smaller limit. The program-header limit is 4096. ELF identification/header versions, program-header tables, segment bounds and `p_filesz <= p_memsz`, the dynamic table, virtual-address mapping for `DT_STRTAB`, dependency offsets, UTF-8 strings, and NUL terminators are validated before reporting. Unsupported extended program-header counts and malformed or ambiguous interpreter/dynamic/ABI-flags structures raise `ElfInspectionError`; a partial success report is not returned.

Tests build small ELF bytes directly in the test suite. They are first-party synthetic fixtures and are inspected as data only; no ELF fixture is executed or generated with a compiler.
